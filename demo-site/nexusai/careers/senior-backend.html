Senior Backend Engineer - Distributed Systems

Location: Remote (US / Europe / Hybrid)

Team: Platform Infrastructure

Role Overview

We are seeking a Senior Backend Engineer to design and scale our real-time inference routing engines and distributed storage pipelines.

Responsibilities

  • Design, deploy, and maintain high-throughput backend services using TypeScript and Node.js.
  • Architect database models and execute zero-downtime PostgreSQL migrations.
  • Optimize system performance, latency, and resource utilization across Kubernetes clusters.
  • Mentor junior engineers and champion clean code standards and test automation.

Requirements

  • 5+ years building backend web services and distributed systems in production (required).
  • Expert proficiency in TypeScript and Node.js backend development (required).
  • Deep knowledge of relational databases, especially PostgreSQL indexing and query optimization (required).
  • Experience with Docker and Kubernetes container orchestration (nice to have).
  • Strong written communication and empathetic collaboration skills (essential).
